# I LOVE BOOSTERS · Boots Riley in Durham

Event page for the echo × Duke Cinematic Arts multi-day experience around
Boots Riley's *I LOVE BOOSTERS* (Sept 17–18, 2026).

Static site, no build step. Open `index.html` or serve the folder:

```bash
python3 -m http.server 8000
```

## Hosting on GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)`.
The site will publish at https://quinciking.github.io/echo/
